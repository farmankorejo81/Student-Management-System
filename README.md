
# Student Management System

A simple desktop application built with Java Swing and AWT that allows users to manage student records dynamically using a structured GUI table.

## 🚀 Features
- **Add Records:** Insert Student ID, Name, Age, and Course into the system.
- **Delete Records:** Select and remove any row directly from the table view.
- **Input Validation:** Shows alert popups if required fields are left empty.
- **Form Reset:** Clear input fields instantly using the Clear button.
- **Interactive UI:** Dynamic `JTable` with auto-scrolling capabilities.

## 🛠️ Built With
- **Language:** Java
- **GUI Framework:** Java Swing (`javax.swing.*`) & AWT (`java.awt.*`)
